\begin{abstract}
We present \framework, a compact benchmark and evaluation protocol for
diagnosing specification failures in reinforcement learning. The benchmark
factorizes each task into environment dynamics, proxy reward, hidden true
objective, corruption channel, monitor channel, distribution shift, and policy
family, so benchmark claims can be tied to explicit assumptions rather than
bundled environment details. We instantiate this protocol in three symbolic
environments, pair it with an executable artifact containing schema exports,
leakage diagnostics, and paper assets linked directly to saved outputs, and
evaluate proxy-trained PPO against an oracle diagnostic baseline under fixed
laptop-scale budgets. Across all three tasks, proxy training underperforms
oracle training on the hidden objective; SensorTamper-v0 additionally exposes a
behaviorally active tamper channel whose removal collapses the learned exploit;
and monitor evaluation is informative but narrow, because only SensorTamper-v0
yields a nondegenerate, leakage-cleared hack-monitor task under the current
proxy-only protocol. The contribution is therefore not a new RL algorithm, but
a compact evaluation benchmark that makes reward misspecification, tampering,
and monitorability claims more explicit, reproducible, and falsifiable.
\end{abstract}
