\section{Experimental Setup}
We evaluate three symbolic tasks, two policy families, and deterministic ID/OOD
variants under a fixed local-compute budget. Each environment is trained with
three random seeds. ProxyFarming and SensorTamper use 200,000 PPO steps per run
and the recalibrated GemTimeout uses 60,000. Oracle True PPO is included only
as a diagnosis baseline for the hidden objective, not as a deployable method.

Monitor evaluation is stricter than the policy benchmark. Monitor datasets are
built from stochastic rollouts of the proxy-trained policy family only, and
restricted versus rich audit channels are evaluated with logistic regression and
gradient boosting under run-aware splits. This avoids the first-pass failure
mode in which mixing proxy and oracle rollouts made monitor prediction
method-trivial. In addition to AUC metrics, we report hack-label and
failure-label support so that accepted monitor results can be separated from
degenerate monitor tasks.
