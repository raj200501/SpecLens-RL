\section{Experimental Protocol}
\label{sec:protocol}

\paragraph{Agents.} The policy class $\Pi$ is PPO \citep{schulman2017ppo} in a
single-file CleanRL-style implementation \citep{huang2022cleanrl}:
\res{n-envs} synchronous environments, rollouts of \res{rollout-steps} steps,
GAE($\lambda{=}\res{gae-lambda}$), $\gamma{=}\res{gamma}$, \res{epochs} epochs
of minibatch size \res{minibatch}, a learning rate of \res{lr} decayed linearly
to zero, and entropy coefficient \res{entropy}. The network is two $3{\times}3$
convolutions with \res{channels} channels followed by a \res{hidden}-unit hidden
layer. \emph{Proxy PPO} is trained on $R_p$; \emph{Oracle PPO} is the same
algorithm trained on $J_t$ and serves as a reference for what the budget can
achieve, not as a deployable method. Each run uses \res{steps} environment
steps; the main comparison uses \res{seeds} seeds per task and method. All
settings (Appendix Table~\ref{tab:hparams}) are identical across tasks and
methods.

\paragraph{Evaluation.} Each final policy is evaluated on \res{eval-episodes}
fresh layouts per split, with actions sampled from the policy, which is the
behavior PPO optimizes. Every policy sees the same layouts, so comparisons are
paired. Training runs are the independent units: we average episodes within a
run and report the mean over runs with a 95\% Student-$t$ interval (clipped to
$[0,1]$ for rates). With 5--10 runs, percentile-bootstrap intervals cover
noticeably less than their nominal 95\%, which is why we do not use them.

\paragraph{Training dynamics and dose--response.} Each run saves
\res{snapshots} evenly spaced policy snapshots, which are evaluated on
\res{curve-episodes} fixed ID layouts to trace proxy return, true return and
hack rate over training. For the dose--response experiment we retrain Proxy PPO
with channel scale $\lambda\in\{\res{sweep-scales}\}$ (times the default
bonus), with \res{sweep-seeds} seeds per value.

\paragraph{Monitors.} A monitor sees one finished trajectory and outputs a hack
score. Because hacking emerges during training, each task's monitor dataset
pools stochastic rollouts of \res{monitor-snapshots} snapshots of every Proxy
PPO and every Oracle PPO run (\res{monitor-layouts} layouts per snapshot and
split), \res{monitor-episodes} ID episodes per task. Monitor channels are
defined by the provenance of their features, i.e.\ the trajectory fields each
feature is computed from; provenance is enforced in code by computing every
feature on a copy of the trajectory restricted to its declared fields.
\begin{itemize}[leftmargin=*,itemsep=1pt]
\item \textbf{behavior} (\res{n-features-behavior} features): positions and
actions. The monitor knows nothing about the task layout, but it does see how
long the episode lasted, and in \PF{} and \ST{} an episode ends early only when
the task is completed.
\item \textbf{task} (\res{n-features-task} features): additionally the goal
cell.
\item \textbf{privileged} (\res{n-features-privileged} features): additionally
the cells through which the channel is accessed. Hack labels are functions of
exactly these fields, so this channel can reconstruct them and serves as a
positive control.
\end{itemize}
We fit logistic regression and gradient-boosted trees with leave-one-seed-out
cross-validation: each fold holds out the proxy and oracle runs of one seed,
so the monitor is always scored on policy lineages it has never seen. We report
the mean held-out ROC-AUC with a $t$ interval over folds, the
\emph{within-snapshot} AUC (the mean AUC within each run's snapshot, i.e.\
among episodes of a single policy), and two transfer tests: training on ID
episodes and testing on the held-out seed's OOD episodes, and training on the
first half of training and testing on the second half.

\paragraph{Baselines a monitor must beat.} Hacking becomes more common as proxy
training proceeds, so a monitor could score well by recognizing which policy
produced an episode rather than what it did. The \emph{policy-identity}
baseline is a logistic regression on the method and snapshot index alone. The
\emph{single-feature} baseline uses the best individual feature, with the
feature and its sign chosen on the training folds only.

\paragraph{Admissibility.} A monitor result is \emph{admissible} if the label is
non-degenerate (minority class at least 5\%) and the channel does not see every
field the task's hack label is computed from (positions and channel cells, plus
actions in \ST{}). A channel that sees all of them can compute the label
directly, so its score says nothing about monitorability. We additionally flag a
result as \emph{trivial} when the selected single feature already reaches a
held-out AUC of 0.98. The privileged channel must be inadmissible and should be
trivial; it is the positive control for the screen.

\paragraph{Training against a monitor.} Finally we fit a logistic behavior
monitor on all main-experiment episodes of a task and train \res{pen-seeds}
fresh Proxy PPO agents (new seeds) whose reward at the end of each episode is
reduced by $\beta=\res{pen-beta}$ times the monitor's hack probability. We
compare the monitor's recall on hacking episodes of these agents with its
out-of-run recall on the unpenalized final policies.
